async-hyperliquid
=================

``async-hyperliquid`` is an asynchronous, typed Python client for Hyperliquid's
HTTP Info and Exchange APIs. It separates credential-free reads from signed
actions and makes network, endpoint, account, and vault routing explicit.

Start with the read-only quickstart. Before enabling signed actions, read the
account-routing, endpoint-trust, and reconciliation guidance.
